# architecture-insuretech

Проектная работа 8 спринта курса "Архитектор ПО" (Яндекс Практикум). Компания InsureTech, агрегатор страховых услуг.

## Задания

1. Task1 - технологическая архитектура (схема draw.io)
2. Task2 - динамическое масштабирование контейнеров в Kubernetes (HPA, Prometheus, Locust)
3. Task3 - переход на Event-Driven архитектуру (диаграмма C4)
4. Task4 - проектирование продажи ОСАГО (диаграмма C4)
5. Task5 - GraphQL API сервиса client-info
6. Task6 - Rate Limiting в nginx
